by day

It reads, remembers, and reports.

briefs
A morning brief, a news digest, inbox triage, weekly transactions, one curiosity question a day. Keep the ones you want.
accounts
Gmail, Calendar, Drive, iMessage, Slack, a browser, your finances. Reads pass a prompt-injection firewall. Anything that sends or changes something waits for your go.
memory
Plain Markdown in git. Searchable from your terminal, readable and editable without the assistant.
web app
A private page on your own network: every brief, your library, a monitor for each scheduled job.
watchdog
Checks the Mac every five minutes and messages you when a job hangs, stops firing, or memory runs short.
private
This engine is public. Your identity, memory, and secrets live in a separate folder you own. Secrets stay in the macOS Keychain.

by night

It dreams while you sleep.

A model wakes up blank every session. So overnight, scheduled jobs replay the day, keep what matters, and repair the assistant's own notes and instructions. Memory lives in git, so a bad edit is one revert away.

  1. 22:00

    Alignment twice a week

    Audits its own instructions and skills for contradictions and stale claims. Applies the clear fixes and brings you the real decisions, five at most.

  2. 22:30

    Dedup weekly

    Reads all of memory at once and hunts for duplicates and contradictions. Names, dates, family, and money are flagged for you, never edited.

  3. 01:00

    Consolidation nightly

    Turns yesterday's raw conversations into one clean, tagged daily note.

  4. 01:30

    Descriptions nightly

    Keeps a one-line summary and tags on every memory file, so the next session knows what to open.

  5. 02:27

    Deep consolidation weekly

    Reviews the whole week against everything it knows, updates the long-term notes, and writes you a report.

  6. 07:00

    Morning brief daily

    And then it tells you what today holds.

get it

Four commands, then say hello.

> git clone https://github.com/Maninae/mineru-assistant.git
> cd mineru-assistant && python3 -m venv .venv && source .venv/bin/activate
> pip install -e .
> mineru setup

Setup asks for a name, a persona, and a time zone, then walks you through the secrets it needs: a Telegram bot token, Google access, a Claude Code login. Message your bot what's on today? and it answers.

It runs its author's assistant every day. Setting up a fresh one is the part still being smoothed, so expect rough edges and say so in an issue.

Built by Owen Wang for one household, and shared in case yours wants one too.
