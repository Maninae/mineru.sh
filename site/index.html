Mineru

A personal AI assistant that lives on your own machine.

memory
Plain Markdown files, versioned in git. Readable and editable without the assistant.
jobs
A morning brief, inbox triage, a finance check, and whatever else you put on the schedule.
talk
A conversation over Telegram by day. Memory consolidation by night.

Named after the Sage of Spirit. Built by Owen Wang. The engine opens on GitHub soon.
